## Method, and what it cannot see

- Attribution is by bare test name: cargo prints `test NAME ... ok` without
  naming the binary. `test-inventory.txt` asserts every bare name is unique
  workspace-wide, which is what makes that sound.
- The 2 `#[ignore]`d test(s) never run and are absent from the table above
  by construction; `known-red.md` is their register.
- Bash suite tests are counted per FILE (`test-foo.sh`) — the only unit its
  runner reports.
- **Known nondeterminism this census would NOT catch:** `story next`,
  `story summary`, `story context` and `story handoff` order same-priority
  stories by a `created_at` with *second* precision, so identical input can
  yield different orderings (`docs/rearch/STATE.md`, W0.3 finding #1). The
  golden corpus works around it with a deliberate `>=1s` sleep rather than
  fixing it. If an ordering flake ever appears in the table above, it is
  that defect resurfacing — not a new one.
