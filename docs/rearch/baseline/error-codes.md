The machine-readable half of this CLI's interface, extracted from
`tests/error_contract.rs` — the enforcing test itself, not a copy of one. Exit codes
are load-bearing: `plugin/claude-code/bin/story.sh` branches on exit 9 to
detect a lost compare-and-swap claim, and exit 3 is how any caller learns an
id does not exist.

## Stream placement (the SH-59 ruling)

| form | stream | body |
|---|---|---|
| plain | **stderr**; stdout empty | `error: {message}` + newline |
| `--json` | **stdout**; stderr empty | the envelope below |

stdout is the machine-readable result channel — exactly one self-describing
document per run — so a `--json` failure envelope belongs there, and a failed
plain run writes nothing to stdout at all. stderr also carries free-text hook
warnings, which is why it cannot be the JSON channel.

### Notes

- **`StateConflict` is the one envelope exception.** Its `result` is
  `"conflict"`, not `"error"`, and it carries `expected` + `actual`: a lost
  compare-and-swap is a *result a caller acts on*, not a failure it reports.
  `story.sh`'s CAS claim reads `actual` to report who won the story.
- **`SyncConflict` (exit 8) is dead code.** It is constructed nowhere in
  `src/`; only `src/web.rs` maps it to HTTP 409. `tests/error_contract.rs` covers its
  exit code at the enum level and lists it `UNREACHABLE`. See
  `docs/rearch/STATE.md`, W0.3 finding #3 — it needs a story, or a deletion.
- **`GithubAuth` / `GithubApi` are feature-gated** behind the default-on
  `github-sync` feature. `--no-default-features` compiles them out, and the
  contract test skips their rows accordingly; a capture taken without the
  feature would show them as unreachable.
- **The message fragments are fragments on purpose.** This table pins the
  *contract*. Exact prose is pinned once, in the golden corpus
  (`tests/snapshots/`), so a wording change fails one test and not two.
- **The envelope key set is itself the contract.** A new key is a compatible
  addition only once every consumer tolerates it, so the test asserts the
  exact key list, sorted.
- **`LockTimeout` costs ~5s to provoke** and is the single largest fixed cost
  in the gate; see `timings.md`.
